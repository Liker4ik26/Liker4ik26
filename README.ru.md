## Привет, я Анжелика. Можно Лика

Я **Middle Flutter Developer** из Омска, работаю удалённо. Создаю **мобильные и десктопные приложения для iOS, Android, Windows и macOS**, развиваю существующую кодовую базу и сопровождаю задачи от разбора требований до релиза и поддержки после выпуска.

Работаю с архитектурой модулей, API, потоковыми AI-ответами, медиа, платежами и автоматизированными тестами. Также занимаюсь ручным функциональным и smoke-тестированием, пишу тест-кейсы и проверяю API в Postman.

Сейчас — **веб-студия «Регул»** (январь 2025 — настоящее время), ранее — **XNS** (март 2023 — декабрь 2024). Русский — родной · Английский — B1.

## Коротко о важных задачах

- **Рефакторинг архитектуры за два месяца:** участвовала в миграции Nylo → BLoC, разделяла UI, состояния и данные, покрывала старое поведение тестами.
- **Сложный баг за один день:** нашла ошибку обработки прогресса, из-за которой завершённые материалы оставались непрочитанными.
- **Потоковый AI-интерфейс:** буферизация SSE-данных и согласование состояний с последовательной анимацией текста.
- **Два разработчика в менторинге:** code review, парное программирование, погружение в кодовую базу и разбор архитектуры.
- **Сборки для четырёх платформ:** iOS, Android, Windows и macOS; мобильные сборки — TestFlight, App Store и Google Play.
